# Yuvamdaki Yıldızlar – Gizlilik Politikası

`index.html`, GitHub Pages ile yayımlanabilecek tek sayfalık politika dosyasıdır.

Geliştirici ve iletişim bilgileri sayfaya işlendi. Yayımlamadan önce e-posta adresinin doğru yazıldığını kontrol edin.

Dosyayı GitHub deposunun köküne `index.html` adıyla koyduktan sonra depo ayarlarından GitHub Pages'i bu daldan/kök dizinden yayımlayın. Google Play Console'daki gizlilik politikası alanına yayımlanan HTTPS adresini girin.
